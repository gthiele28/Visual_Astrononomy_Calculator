TO RUN THIS PROJECT:
1) Follow the instructions in full_process.py (you may have to change the chromedriver 
version and path to fit your own OS/CPU and browser version)
2) Run full_process.py, answer its questions on the command line (Note also that current location
   is by IP address, so not perfectly accurate
3) Check visible_objects.txt for the objects you can see, their NGC/IC entry number, coordinates,
   magnitudes, etc.  Unless you have a really good telescope and really dark skies, you probably
   won't be too overwhelmed, but if you want the most famous objects check for the ones with
   common names.
4) Have fun!  Also note this may not be perfectly accurate due to my simplifying some of the
   more complex aspects of light pollution, moonlight, atmospheric disturbances getting in
   the way, etc.
